# Hola Mundo Móvil

Proyecto simple de ejemplo para uso en celular, creado con HTML, CSS y JavaScript.

## Archivos

- index.html: interfaz principal.
- data.js: datos de ejemplo.
- app.js: lógica de la aplicación.
- README.md: documentación del proyecto.
- LICENSE: licencia MIT.

## Cómo usar

1. Abre index.html en un navegador.
2. Si lo quieres ver desde el celular, puedes subirlo a GitHub y activar GitHub Pages.
3. Edita data.js para cambiar los elementos de la lista.

## Datos

Los datos están en data.js dentro de la constante DATOS.

Cada elemento puede tener:

- id
- titulo
- detalle
